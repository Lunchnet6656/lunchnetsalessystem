## モデル設計メモ

称号はLvの閾値で自動付与するため、`Title` モデルで管理する想定:

```python
class Title(models.Model):
    level_required = models.IntegerField(unique=True)   # 解放Lv
    key = models.CharField(max_length=50, unique=True)  # 識別キー
    name = models.CharField(max_length=50)              # 称号名
    description = models.TextField()                    # 説明文
    image = models.ImageField(
        upload_to='quest/titles/',
        null=True,
        blank=True,
        help_text='未設定時はデフォルト画像を使用'
    )

    class Meta:
        ordering = ['level_required']

    def __str__(self):
        return f"Lv{self.level_required} {self.name}"

    def get_image_url(self):
        """画像URLを返す。未設定時はデフォルト画像。"""
        if self.image:
            return self.image.url
        return settings.STATIC_URL + 'quest/img/titles/default_title.png'
```

ユーザーへの付与は `services.py` の `get_title_for_level(level)` で実装予定:

```python
def get_title_for_level(level: int) -> Title | None:
    """levelに対応する最高の称号を返す"""
    return Title.objects.filter(level_required__lte=level).order_by('-level_required').first()
```
