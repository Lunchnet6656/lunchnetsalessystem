# 給与計算ロジック 変更履歴（戻せるように保存）

勤怠アプリ（attendance）の賃金計算ロジックの変遷を記録する。
「いつでも前の方式に戻せる」ための原典。実コードは `attendance/payroll.py` の `compute_payslip`。

---

## 【v1】割増＝上乗せ式（〜2026-06-03 まで稼働した現行ロジック）

> しょうへいの指示「時間外などを 1.25 倍の独立単価で計算したい」を受けて v2 へ移行する前の方式。
> 一般的・法的に正確な「割増＝base に上乗せ」モデル。深夜と時間外が重なると両方が乗る（スタッキング）。

### 考え方
- **基本賃金は全実働を 1.0 倍でカバーする**（時間外・深夜・休日に該当する分も、まず 1.0 倍で基本賃金に含む）。
- 時間外・深夜・休日の各割増は「**上乗せ分（surcharge）だけ**」を加算する。
  - 例：深夜かつ時間外の 1 分 → 基本 1.0 ＋ 時間外 0.25 ＋ 深夜 0.25 ＝ 1.5 倍。
- だから `overtime_rate=0.25 / night_rate=0.25 / holiday_rate=0.35` は **「+α の率」**として使う。

### 計算式（Decimal、`_yen(min, wage, rate) = min/60 × wage × rate`）
```
work          = 実働（分）。休憩控除後。時間外・深夜・休日に該当する分も含む総実働。
ot_under60    = min(overtime, 60h)         # 月60時間以内の時間外
over60h       = max(0, overtime - 60h)     # 月60時間超の時間外

base_yen      = round( _yen(work, wage) )                          # 全実働 × 時給 × 1.0
overtime_yen  = round( _yen(ot_under60, wage, 0.25)               # ← 上乗せ分のみ
                     + _yen(over60h,    wage, 0.50) )
night_yen     = round( _yen(night,   wage, 0.25) )                 # ← 上乗せ分のみ
holiday_yen   = round( _yen(holiday, wage, 0.35) )                 # ← 上乗せ分のみ
total_yen     = round( base_yen + overtime_yen + night_yen + holiday_yen , 丸め単位 )
```

### 休憩控除の表示（v1 後半で追加）
```
break_deduction_yen = round(_yen(work + break, wage)) - base_yen   # 支給欄の表示分解のみ。金額に影響なし
基本賃金（拘束分）= base_yen + break_deduction_yen
休憩控除          = − break_deduction_yen
```

### この方式の特徴
- 労基法どおりの割増の積み上げ。打刻（食堂）は深夜×時間外の重なりが自然に正しく計算される。
- 手動入力（販売）では「時間外手当」欄が +0.25 分しか見えないため、直感とズレるとの指摘 → v2 へ。

## 【v2】割増＝独立フル単価式（2026-06-03〜）

> しょうへい指示：基本賃金と時間外/深夜/休日を**別建て**にし、時間外などは
> 「**1.25 倍の時給 × 働いた時間**」で独立に計算したい。シンプル優先。
> 適用範囲＝**全スタッフ共通**（打刻＝食堂も）。基本時間の扱い＝**通常時間のみ**（時間外/深夜/休日は別建てで上乗せ）。

### 考え方
- **基本賃金は「通常時間」だけ**を 1.0 倍で支払う（時間外・深夜・休日に該当する分は含めない）。
- 時間外・深夜・休日は **それぞれ「フル単価 ＝ 1 ＋ 上乗せ率」× 時間** で独立に計算し、単純合計する。
  - フル単価：時間外 ×1.25／60h 超 ×1.50／深夜 ×1.25／休日 ×1.35（率は `PayrollSetting` の既存値を `1+率` で流用）。

### 「通常時間（normal）」の出し方（入力経路で異なる）
- **手動入力（販売）**：`勤務時間（拘束）` 欄＝**通常勤務のみ**。`normal = 勤務拘束 − 休憩`。
  時間外・深夜・休日はそれぞれ別欄で入力し、normal には含めない（上乗せ）。総実働＝normal＋時間外＋深夜＋休日。
- **打刻（食堂）**：打刻から総実働 W・時間外・深夜を算出し、`normal = max(0, W − 時間外 − 深夜 − 休日)`。
  ⚠ 深夜と時間外が重なると二重控除されうる（食堂は深夜≒0のため実用上は無視）。

### 割増の端数処理（2026-06-03 確定・基発150号準拠）
- 割増は **「四捨五入した時給単価 × 時間」**。単価＝`round_half_up(時給 × フル割増率)`（1円単位）。
  - 例：1225×1.25=1531.25 → 25銭切捨 → 単価1531。1226×1.25=1532.5 → 50銭切上 → 単価1533。
- **切り捨て固定は不可**（50銭以上を切ると過少払い＝労基法24条違反）。四捨五入で統一。
- 実装：`payroll.premium_unit_yen(wage, full_rate)` ／ `_premium_yen(minutes, wage, full_rate)`。

### 計算式
```
unit(rate)    = round_half_up( wage × rate )                        # 1時間あたり割増単価（円）
base_yen      = round( _yen(normal, wage) )                         # 通常時間 × 時給 × 1.0
overtime_yen  = round( unit(1.25) × ot_under60/60 )                 # 単価四捨五入 × 時間
              + round( unit(1.50) × over60h/60 )
night_yen     = round( unit(1.25) × night/60 )
holiday_yen   = round( unit(1.35) × holiday/60 )
total_yen     = round( base_yen + overtime_yen + night_yen + holiday_yen , 丸め単位 )

break_deduction_yen = round(_yen(normal + break, wage)) - base_yen  # 支給欄の表示分解（金額に影響なし）
出力 work_minutes   = normal + overtime + night + holiday           # 総実働
normal_minutes      = normal                                        # PDF「基本出勤時間」等に使用
```

### v1 との違い（同じ時間で比べると）
- v1：base＝全実働×1.0、割増＝上乗せのみ。深夜×時間外は積み上げ（1.5 など）。
- v2：base＝通常のみ、割増＝フル単価で別建て。重なりは積み上げず単純合計。
- **非重複なら総支給額は概ね一致**。重なりがある打刻（深夜×時間外）では差が出る（食堂は深夜≒0）。
