# メニュー送信マクロ 導入手順（「メニュー送信.xlsm」）

## 導入するとどうなるか
- 元のメニュー表（`2024～メニュー表.xlsx`）の週のシートを仕上げたら、**「メニュー送信.xlsm」の[メニュー送信]ボタンを1回押すだけ**でアプリにメニューが登録される
- これまでの「アップロード用Excelを作る → 値段と容器を手で入れる → ブラウザでアップロード」は要らなくなる
- **元のメニュー表は1マスも変えない**（読み取り専用で開いて、保存しない）
- 押すと次の順番で動く：
  1. 最初は「今日より後で一番近い水曜のシート」が選ばれている（木曜に押せば翌週の分）
  2. 「10/14(水)週のメニュー10品をアプリに送ります。①… ⑩…」と確認。［いいえ］で別の週のシート名を入れられる
  3. ①〜⑩に空欄がある・⑪⑫に名前がある → 止めて送らない
  4. アプリに送る → 「10/14週 11品を登録しました（要確認 2品）」
  5. **OKを押すと必ずブラウザで「週のメニュー確認」画面が開く** → 種類・容器・値段を確かめて［確認完了］を押す
- 確認し忘れたら、火曜19:30にしょうへいのLINEに通知が来る

事務所PCで1回だけやる作業。所要時間：15分くらい

## 0. 事前にアプリ側でやること（開発部）
- 本番をS4のバージョンにする（`/api/menu/` が入っていること）
- 本番で `python manage.py build_menu_dictionary --apply` を流し、過去のメニューからメニューデータベースを作っておく（最初の送信から、よく出るメニューが自動で決まる）
- Heroku Scheduler に `python manage.py check_menu_week_confirmed` を **毎日 10:30 UTC（=19:30 JST）** で登録（火曜だけ動く）
- 送る人のアカウントに、ユーザー管理で「価格・メニュー設定」をONにする（確認画面を開くため）

## 1. 合言葉ファイルを確かめる
振分表マクロと同じ `lss_token.txt` を使う。次の場所にあればOK（新しく置く必要はない）。
`\\192.168.111.250\Data\共有\◇LSS関係\lss_token.txt`

## 2. 元のメニュー表の場所を確かめる
マクロは次のフォルダの、`メニュー送信.xlsm` の **B2セルに書いたファイル名** を開く（B2が空なら `2024～メニュー表.xlsx`）。
`\\192.168.111.250\Data\共有\○メニュー表\★メニュー表\`
- **年が替わってファイル名が変わったら、B2を書き換えるだけでよい**（マクロは直さない）
- 別のフォルダにあるときは、B2に `\\` から始まる場所ごと書く

## 3. 「メニュー送信.xlsm」を作る
1. Excelで新しいブックを開く
2. `Alt + F11` で VBA の画面を開く → メニューの「ファイル」→「ファイルのインポート」→ `LssMenuSend.bas` を選ぶ
3. VBA の画面を閉じる
4. シートの **A2に「元のメニュー表のファイル名」、B2に `2024～メニュー表.xlsx`** と入力する（実際のファイル名と1文字も違わないように。エクスプローラーでファイル名をコピーして貼り付けると確実）
5. シートにボタンを置く：「開発」タブ →「挿入」→「ボタン（フォームコントロール）」→ シートに描く →「マクロの登録」で `メニュー送信` を選ぶ → ボタンの文字を「メニュー送信」にする
   - 「開発」タブがないとき：「ファイル」→「オプション」→「リボンのユーザー設定」→「開発」にチェック
6. 「名前を付けて保存」→ ファイルの種類を **「Excel マクロ有効ブック（*.xlsm）」** にして、元のメニュー表と同じフォルダに `メニュー送信.xlsm` で保存

## 4. 動作確認（導入した日に1回）
1. 元のメニュー表に、来週のシートがあることを確かめる
2. `メニュー送信.xlsm` を開き、「コンテンツの有効化」を押す
3. [メニュー送信] を押す → 確認の画面で、来週のメニュー10品の名前が正しいか見る → ［はい］
4. 「◯/◯週 11品を登録しました」と出て、OKでブラウザの確認画面が開けば成功
   - ブラウザでログインしていなければ、ログイン画面のあとで確認画面に戻る
5. 確認画面で種類・容器・値段を確かめて［確認完了］

## 困ったとき
| 出たメッセージ | どうするか |
|---|---|
| 元のメニュー表を開けませんでした | 表示された場所にファイルがあるか確かめる。ファイル名が変わったときは `メニュー送信.xlsm` のB2を書き換える |
| 『20261014』のシートが元のメニュー表にありません | 週のシート名（水曜の日付）を確かめる。［いいえ］で別の週も選べる |
| メニューの欄が空欄です | 元のメニュー表の①〜⑩を埋めてから押し直す |
| ⑪⑫の欄にメニューが入力されています | まだ対応していないので開発部に連絡 |
| 合言葉ファイルが見つかりません | 手順1の場所に `lss_token.txt` があるか確かめる |
| 〇〇週は終了しています | 終わった週は変えられない。直すなら開発部に相談 |
| 送信できませんでした（停止箇所…） | 急ぐときは今までどおり、LSSの「データアップロード」からアップロード用Excelで登録できる |

## 古い登録方法との関係
- 移行期間は、今までのアップロード用Excel（値段の欄あり）もそのまま使える
- 新しい方法で送った週は、値段が**価格表**で決まる（Excelの単価は使わない）
- 同じ週を両方で登録すると、後から登録したほうで上書きされる。切り替えた週からは、メニュー送信だけを使う
